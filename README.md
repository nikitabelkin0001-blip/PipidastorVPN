# Pipidastr VPN

Windows-клиент для VLESS/Reality, VLESS/TLS, шифрованного VLESS и Hysteria2. [Xray-core](https://github.com/XTLS/Xray-core) устанавливает соединение с сервером, а [sing-box](https://sing-box.sagernet.org/) создаёт системный TUN и маршрутизирует трафик приложений. Есть профили для выбранных приложений и всего трафика, импорт HTTPS-подписок. Discord по умолчанию идёт через VPN, а `winws.exe` — напрямую.

## Установка на Windows

1. Откройте раздел **Releases** этого репозитория и скачайте файл `PipidastrVPN-portable-win-x64.zip` из последнего выпуска. Архив GitHub с названием **Source code** для запуска не подходит.
2. Распакуйте **весь** архив в отдельную папку, например `Загрузки\ВПН`. Не запускайте `.exe` прямо из архива и не вынимайте его из папки отдельно: рядом нужны `sing-box.exe` и `xray.exe`.
3. Запустите `PipidastrVPN.exe` и подтвердите запрос Windows на права администратора. Устанавливать .NET отдельно не нужно: он включён в portable-сборку.
4. Нажмите `+` рядом с выбором профиля и задайте название и режим. Добавьте **свою** HTTPS-ссылку на подписку кнопкой «Добавить подписку» под списком серверов либо на странице профиля, затем обновите серверы. Кнопка «Удалить подписку» удаляет ссылку и все серверы этого профиля после подтверждения.
5. Выберите сервер слева и нажмите «Подключить». Для режима «Выбранные приложения» откройте «Настроить приложения», затем выберите запущенную программу или файл `.exe`. Для режима «Весь трафик» тот же выбор добавляет исключения. Изменения маршрутизации применяются после переподключения.

Список серверов можно фильтровать строкой поиска. В списках приложений показываются короткие имена и значки программ; если значок недоступен, используется логотип клиента. Полосы прокрутки оформлены в цветах приложения.

В режиме «Выбранные приложения» сайты в браузере открываются через VPN только после добавления исполняемого файла браузера в «Приложения через VPN». После изменения списка переподключите VPN и перезапустите браузер.

Чтобы удалить portable-клиент, отключите VPN, закройте программу и удалите папку, в которую распаковали архив. Настройки отдельно находятся в `%LOCALAPPDATA%\PipidastrVPN`.

Если сервер подписки требует идентификатор устройства, клиент автоматически создаёт постоянный случайный ID и повторяет запрос. ID отправляется только на адрес подписки при обновлении. Провайдер может учесть эту программу как отдельное устройство. Если лимит устройств уже исчерпан, потребуется освободить место в кабинете провайдера. Ответ-заглушка с просьбой включить HWID не добавляется как сервер.

Подписки и ссылки сохраняются в `%LOCALAPPDATA%\PipidastrVPN\profiles.json`, а созданный ID — в `device-id.txt`. Файлы хранятся в открытом виде. Не отправляйте их другим людям. Профили прежней версии переносятся автоматически.

## Zapret Discord

`Discord.exe` направляется через VPN, а процесс Zapret `winws.exe` — напрямую. При обновлении старых профилей прежнее исключение для Discord переносится в список приложений через VPN. Это позволяет новым соединениям Discord, включая передачу экрана, обходить конфликт TUN с фильтрацией Zapret. Изменения применяются после перезапуска клиента и подключения. Если Discord добавлен как исключение вручную после обновления, настройку можно изменить на странице профиля.

TUN использует стек gVisor для TCP и UDP. Клиент объявляет только IPv4-маршрут и запрашивает IPv4-адреса в DNS: на этой Windows-конфигурации соединения по IPv6 обрывались. Это может помочь, если голос Discord работает, но предпросмотр демонстрации становится чёрным только при включённом VPN. После замены portable-сборки полностью закройте Discord, подключите VPN и запустите Discord заново. Если предпросмотр остаётся чёрным, проверьте настройку «Аппаратное ускорение» в Discord → «Голос и видео» → «Видео» и попробуйте демонстрацию всего экрана вместо отдельного окна.

DNS-запросы при подключённом TUN отправляются через VPN по HTTPS, а UDP-сессии сохраняются до 15 минут бездействия. Поэтому Discord можно запускать после подключения VPN; для уже открытого Discord переподключитесь к голосовому каналу. Если сервер не сразу отвечает на проверочный HTTPS-запрос, клиент повторяет её дважды перед сообщением об ошибке.

## Ограничения первой версии

Если Windows временно не успела настроить TUN-адаптер, клиент повторяет его запуск дважды. При повторяющейся ошибке `set ipv4 address: Element not found` проверьте, включён ли компонент TCP/IPv4 у сетевых адаптеров, и перезагрузите Windows. Ошибку браузера проверяйте после успешного запуска туннеля.

Журнал последнего и предыдущих запусков находится в `%LOCALAPPDATA%\PipidastrVPN\session.log`; после 2 МБ он переносится в `session.log.old`. Журнал может содержать адреса посещённых сайтов, поэтому не публикуйте его целиком.

- Поддерживаются VLESS с Reality или TLS через TCP или gRPC, шифрованный VLESS без TLS и Hysteria2. При обновлении подписки клиент сообщает, сколько записей других типов пропущено и почему.
- Нет установщика, автозапуска и фоновой службы. Закрытие окна останавливает туннель.
- Перед запуском TUN клиент проверяет HTTPS-запрос через выбранный VPN-сервер и показывает выходной IP. Это подтверждает работу транспорта; доступность отдельных приложений и правил маршрутизации зависит от Windows и их сетевого стека.
- Для TUN нужны права администратора: Windows показывает стандартный запрос UAC при запуске. Приложения, работающие через собственный сетевой стек или другие VPN-драйверы, могут вести себя иначе.

## Проверка и исходники

`dotnet run --project VpnClient.SmokeTests/VpnClient.SmokeTests.csproj` проверяет разбор ссылок, импорт подписок, оба режима маршрутизации и конфигурации обоих движков. Бинарные движки взяты из официальных релизов [sing-box 1.14.4](https://github.com/SagerNet/sing-box/releases/tag/v1.14.4) и [Xray-core 26.11.9](https://github.com/XTLS/Xray-core/releases/tag/v26.11.9); их лицензии находятся рядом с бинарниками.
