# Удержание кнопки VPN в Atoll

Файл [Atoll-v1.7.1-vpn-hold.patch](Atoll-v1.7.1-vpn-hold.patch) применяется к официальным исходникам [Atoll v1.7.1](https://github.com/Fuwni/dynamic-island-windows/tree/v1.7.1) (MIT). Он добавляет PipidastrVPN в поиск VPN-приложений, оставляет короткое нажатие переключателем VPN и открывает окно клиента после удержания 650 мс. При отпускании после удержания переключение не выполняется.

На компьютере, где выполнялась проверка, Atoll собран под .NET 9, поскольку SDK .NET 10 не установлен. После сборки заменён только `DynamicIsland.dll`; исходный модуль сохранён рядом как `DynamicIsland.before-vpn-hold.dll`. Настройки Atoll остались на месте. Проверены оба действия кнопки на установленной панели.

После обновления Atoll его установщик может заменить модуль. Для новой версии сначала сравните исходники обработчика кнопки; патч рассчитан на v1.7.1.
