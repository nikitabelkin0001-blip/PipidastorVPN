# Изменения

## Не выпущено

- Подписки: добавлена поддержка VLESS/TLS, gRPC, шифрованного VLESS и Hysteria2. Параметры `pcs` и `fm` передаются в Xray; при импорте показываются количество и причины пропуска неподдерживаемых записей.
- Управление подпиской: кнопки добавления и удаления заменили добавление и удаление серверов по одному. Удаление подписки очищает ссылку и список серверов текущего профиля после подтверждения.
- Discord: для UDP в TUN используется стек gVisor (`mixed`), а `Discord.exe` направляется через VPN при сохранении прямого маршрута для `winws.exe`.
- Интерфейс: добавлены поиск серверов, более широкая панель, короткие имена и значки приложений, стилизованные полосы прокрутки и новый логотип клиента.
- Иконка приложения встроена в `PipidastrVPN.exe`, чтобы Проводник Windows показывал логотип клиента.
- Portable-сборка: `sing-box.exe`, `xray.exe` и `libcronet.dll` сохраняются рядом с основным исполняемым файлом.
