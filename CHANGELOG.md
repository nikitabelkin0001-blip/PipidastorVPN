# Изменения

## Android и Android TV 0.6

- Рядом со списком серверов добавлены «Тест пинга», «Обновить подписку» и «Найти резервный сервер». TCP-задержка отображается в строках серверов; тест можно отменить.
- Если прямое подключение не передаёт HTTPS, Xray пробует цепочку через VLESS-резерв. Успешный резерв сохраняется. Ручной поиск переподключает VPN; доступна отмена подключения.
- Проверка соединения требует HTTPS-ответ с IP-адресом. В журнале отмечаются этапы запуска, ошибки и успешная проверка цепочки.
- На Android 13+ локальная подсеть исключена из туннеля, а физическая сеть явно передаётся Android как основная для VPN.

## Исправление зависших процессов VPN в Windows

- Xray и sing-box привязаны к процессу клиента через Windows Job Object. При аварийном завершении клиента Windows завершает и его движки, освобождая TUN-адаптер.
- Такая же защита добавлена для временных процессов поиска резервного сервера.
- Добавлена проверка автоматического завершения дочернего процесса при закрытии Job Object.

## Поиск резервного сервера Windows

- Добавлена кнопка «Найти резервный сервер», прогресс проверки и отмена поиска. Под кнопкой отображается выбранный резерв.
- Проверяется HTTPS через отдельный кандидат и через полную цепочку до выбранного основного сервера. Внешнее соединение проверки привязано к физическому Wi-Fi/Ethernet, чтобы другой VPN не дал ложный результат.
- Рабочий резерв сохраняется для текущего профиля без отключения действующего туннеля. При отмене или отсутствии результата прежний резерв сохраняется.

## Кнопки серверов Windows

- Добавлены «Тест пинга» и «Обновить подписку» под компактным полем поиска.
- Тест измеряет время TCP-подключения, показывает результат у каждого сервера и поддерживает отмену. Hysteria2 отмечается как UDP: TCP-проверка для него не выполняется. Результаты не сохраняются в подписке.
- Обновление подписки сохраняет выбранный сервер по ссылке или имени и допускается при работающем VPN; текущий туннель не перезапускается.

## Исправление кнопки VPN на Android TV

- Значок Pipidastr открывает окно клиента без автоматического переключения VPN.
- Для Plume 1.7.1 добавлен патч: короткое нажатие верхней кнопки VPN переключает Pipidastr, удержание открывает его окно. Прямая привязка кнопки к Happ удалена.

## Не выпущено

- Интеграция с Atoll 1.7.1: удержание кнопки VPN открывает окно Pipidastr без отключения; короткое нажатие по-прежнему включает или выключает VPN. Изменение панели сохранено отдельным патчем в `tools/`.

- Windows: закрытие окна оставляет VPN работающим в трее; повторный запуск переключает соединение, `--show` открывает окно. Выбранный профиль сохраняется между запусками.
- Android TV: значок приложения в лаунчере включает и выключает выбранный сервер; настройки открываются через уведомление VPN. На телефоне и ТВ соединение сохраняется при выходе на главный экран.

- Подписки: добавлена поддержка VLESS/TLS, gRPC, шифрованного VLESS и Hysteria2. Параметры `pcs` и `fm` передаются в Xray; при импорте показываются количество и причины пропуска неподдерживаемых записей.
- Управление подпиской: кнопки добавления и удаления заменили добавление и удаление серверов по одному. Удаление подписки очищает ссылку и список серверов текущего профиля после подтверждения.
- Discord: для UDP в TUN используется стек gVisor (`mixed`), а `Discord.exe` направляется через VPN при сохранении прямого маршрута для `winws.exe`.
- Интерфейс: добавлены поиск серверов, более широкая панель, короткие имена и значки приложений, стилизованные полосы прокрутки и новый логотип клиента.
- Иконка приложения встроена в `PipidastrVPN.exe`, чтобы Проводник Windows показывал логотип клиента.
- Системная строка заголовка и кнопки окон оформлены в тёмных цветах приложения.
- Portable-сборка: `sing-box.exe`, `xray.exe` и `libcronet.dll` сохраняются рядом с основным исполняемым файлом.
