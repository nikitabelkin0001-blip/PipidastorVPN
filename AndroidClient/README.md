# Pipidastr VPN для Android

Первый этап: отдельное Android-приложение для импорта HTTPS-подписки VLESS/Hysteria2, просмотра и выбора серверов. На телефоне главный экран показывает подключение и серверы; кнопка с тремя полосками открывает настройки подписки, выбор приложений и текущий профиль. На телевизоре текущий профиль расположен под левой колонкой с серверами. Выбранные приложения сохраняются локально, но пока не влияют на трафик. Кнопка подключения не активна: мобильное VPN-ядро ещё не встроено. Приложение не запрашивает разрешение на VPN и не меняет сетевые маршруты.

Для сборки нужны JDK 17, Android SDK Platform 35 и Build Tools 35. Откройте эту папку в Android Studio или запустите `gradlew.bat assembleDebug`; Gradle 8.11.1 загрузит wrapper. Тест на устройстве: `adb install -r app/build/outputs/apk/debug/app-debug.apk`.

В `tests/test-subscription.txt` лежат синтетические ссылки на `example.com` и `example.org` для проверки импорта. Подключиться к этим адресам нельзя.

Подписка загружается только по HTTPS. Адрес подписки, выбранные приложения и сгенерированный ID устройства хранятся в закрытых настройках приложения; резервное копирование приложения отключено. Ссылки серверов не записываются в журнал. Для общедоступного распространения понадобятся персональные подписки, чтобы не публиковать чужие ключи в APK.

Следующие этапы: Android `VpnService`, совместимое мобильное ядро для поддерживаемых протоколов, выбор приложений для VPN, восстановление соединения, проверка на телефоне.
