# Pipidastr VPN для Android и Android TV

Клиент для Android 8.0+ на ARM64 и ARMv7. Использует Android `VpnService` и официальный `libXray` 26.11.9. Текущая версия приложения — **0.6.0**. [Общее описание проекта](../README.md) · [История изменений](../CHANGELOG.md).

## Подключение

1. Установите APK и откройте Pipidastr VPN.
2. Добавьте свою HTTPS-подписку вручную или по QR-коду.
3. Дождитесь загрузки списка, выберите сервер и нажмите «Подключить».
4. При первом подключении подтвердите системный запрос Android на создание VPN.

Если список приложений пуст, через VPN направляется весь трафик. Иначе используются только выбранные пакеты. Подключение сохраняется при выходе на главный экран: VPN работает как фоновая служба с постоянным уведомлением.

На телефоне кнопка подключения остаётся сверху, прокручивается только список серверов. Поиск фильтрует серверы по имени, адресу и протоколу; настройки открываются кнопкой с тремя полосками. На телевизоре серверы находятся слева, подключение и настройки — справа; элементы доступны с пульта и подсвечиваются при выборе. Иконки приложений загружаются из системы, при их отсутствии используется логотип Pipidastr.

## Серверы и резервный маршрут

Рядом со списком находятся три кнопки:

- **«Тест пинга»** измеряет время TCP-подключения через физическую сеть и показывает результат в строке сервера. Тест можно отменить. Hysteria2 отмечается как UDP, поскольку TCP-проверка для него не выполняется.
- **«Обновить подписку»** загружает актуальный список, сохраняя действующее VPN-подключение.
- **«Найти резервный сервер»** переподключает VPN и проверяет HTTPS через цепочку «устройство → резерв → выбранный сервер → интернет». Успешный резерв сохраняется и проверяется первым при следующем поиске. Кнопка «Отменить» останавливает подключение или поиск.

Если прямой маршрут не передаёт HTTPS, клиент автоматически пробует VLESS-резервы. Статус показывает используемый резерв. В отличие от Windows, Android выполняет поиск последовательно во встроенном ядре и переподключает текущий туннель.

Поддерживаются ссылки VLESS и Hysteria2, включая параметры `fm`, `pcs` и шифрованный VLESS. Количество серверов зависит от актуальной подписки. Совместимость формата ссылки и доступный TCP-порт не гарантируют, что сервер передаёт трафик; для проверки подключения требуется HTTPS-ответ с IP-адресом.

На Android 13+ локальная подсеть исключена из туннеля для доступа к устройствам домашней сети и передачи подписки по QR.

## QR-коды и передача подписки на ТВ

Телефон может прочитать QR-код камерой или из изображения.

Чтобы передать подписку на телевизор, откройте на ТВ «Добавить подписку» → «Получить с телефона по QR», затем считайте код телефоном с Pipidastr и передайте подписку. Оба устройства должны быть в одной Wi-Fi-сети. Код действует две минуты, ссылка передаётся в зашифрованном виде. На телевизоре также доступен ручной ввод ссылки.

## Быстрое подключение на Android TV

Значок приложения открывает окно клиента. В изменённом Plume 1.7.1 короткое нажатие отдельной кнопки VPN переключает выбранный сервер, удержание открывает окно Pipidastr. [Патч Plume](../tools/Plume-v1.7.1-pipidastr.patch) находится в репозитории; установка APK клиента сама по себе не изменяет другой лаунчер.

Удержание обычного значка на главном экране обрабатывает сам лаунчер. При первом подключении через быструю кнопку всё равно потребуется системное разрешение Android.

## Сборка

Нужны JDK 17, Android SDK Platform 35 и Build Tools 35. Укажите установленный SDK через `ANDROID_HOME` или `sdk.dir` в локальном `local.properties`, а JDK — через `JAVA_HOME`.

Из папки `AndroidClient` выполните в PowerShell:

```powershell
.\build-libxray.ps1
.\gradlew.bat assembleDebug
```

Скрипт загружает официальный [libXray 26.11.9](https://github.com/XTLS/libXray/releases/tag/v26.11.9), проверяет SHA-256 и помещает `libXray.aar` в `app/libs`. AAR не хранится в Git и содержит библиотеки для `arm64-v8a` и `armeabi-v7a`.

Отладочный APK: `app/build/outputs/apk/debug/app-debug.apk`. Установка на подключённое устройство:

```shell
adb devices
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Если подключено несколько устройств, укажите нужное через `adb -s <адрес-или-серийный-номер> install -r ...`. Синтетические ссылки из `tests/test-subscription.txt` предназначены только для проверки импорта и не подходят для реального подключения. Для публикации потребуется отдельная release-сборка с ключом подписи.

## Диагностика и хранение данных

Этапы запуска, результаты HTTPS-проверок и ошибки доступны в журнале Android:

```shell
adb logcat -d -s PipidastrVPN
```

При подключённых нескольких устройствах добавьте `-s <адрес-или-серийный-номер>` перед `logcat`. `UnknownHostException` означает, что через текущий маршрут не удалось определить адрес сайта; причиной также может быть отсутствие передачи трафика через VPN-сервер. Проверьте работу через резерв.

Адрес подписки, ID устройства, выбранный сервер и резерв хранятся в закрытом хранилище приложения. Резервное копирование отключено; серверные ссылки не выводятся в журнал. Подписка загружается по HTTPS. Перед распространением сборок проверьте лицензии зависимостей и используйте собственные подписки для каждого пользователя.
