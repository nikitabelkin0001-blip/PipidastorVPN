# Pipidastr VPN для Android и Android TV

Клиент импортирует HTTPS-подписку, показывает совместимые серверы и подключается через Android `VpnService` и официальный `sing-box` `libbox` v1.14.4. На телефоне подключение и серверы находятся на главном экране, настройки открываются кнопкой с тремя полосками. Интерфейс телевизора использует две колонки.

При первом подключении Android запрашивает разрешение на создание VPN. Если список приложений пуст, через VPN направляется весь трафик. Иначе `VpnService` включает только выбранные пакеты. Для работы нужен сервер VLESS с TLS или Reality (TCP либо gRPC) или Hysteria2 без нестандартных параметров Xray. Неподдерживаемые серверы пропускаются при загрузке подписки. Ссылки с `fm`, `pcs`, шифрованным VLESS и Hysteria2 с закреплённым сертификатом пока не поддерживаются.

## Сборка

Нужны JDK 17, Android SDK Platform 35, Build Tools 35, Android NDK 27.2.12479018, Go 1.25 или новее и `github.com/sagernet/gomobile/cmd/gomobile@v0.1.12` в `PATH`. `libbox.aar` не хранится в Git. Сначала соберите его через [build-libbox.ps1](build-libbox.ps1), затем запустите `gradlew.bat assembleDebug` из этой папки. Скрипт собирает исходники официального тега sing-box v1.14.4 для `arm64-v8a` и `armeabi-v7a` и кладёт AAR в `app/libs`.

Отладочный APK: `app/build/outputs/apk/debug/app-debug.apk`. Установка: `adb install -r app/build/outputs/apk/debug/app-debug.apk`. Синтетические ссылки в `tests/test-subscription.txt` проверяют импорт и не подходят для реального подключения.

Подписка загружается по HTTPS. Адрес подписки, ID устройства и выбранные настройки хранятся в закрытом хранилище приложения; резервное копирование отключено. Серверные ссылки не выводятся в журнал. Перед публичным выпуском потребуются персональные подписки и проверка лицензий зависимостей.
