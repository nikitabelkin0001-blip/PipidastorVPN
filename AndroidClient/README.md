# Pipidastr VPN для Android и Android TV

Клиент импортирует HTTPS-подписку, показывает все серверы и подключается через Android `VpnService` и официальный `sing-box` `libbox` v1.14.4. На телефоне подключение остаётся неподвижным, прокручивается только список серверов; поиск находится над списком, настройки открываются кнопкой с тремя полосками. На телевизоре список серверов занимает левую колонку, а подключение и компактные настройки находятся справа.

При первом подключении Android запрашивает разрешение на создание VPN. Если список приложений пуст, через VPN направляется весь трафик. Иначе `VpnService` включает только выбранные пакеты. После запуска клиент проверяет доступ к сайту через VPN и сообщает об ошибке, если сервер не передаёт трафик. Подписка восстанавливается после перезапуска приложения. На телефоне поиск фильтрует серверы по имени, адресу и протоколу.

Телефон может прочитать QR-код подписки камерой или из изображения. Для передачи подписки на телевизор откройте на нём «Добавить подписку» → «Получить с телефона по QR», затем считайте QR-код телефоном с запущенным Pipidastr VPN. Оба устройства должны быть в одной сети Wi-Fi. Код действует две минуты; ссылка передаётся в зашифрованном виде. На ТВ также доступны ручной ввод ссылки и обновление серверов.

Серверы с параметрами, которых нет в текущем ядре, видны в списке с пометкой «нужен Xray», но кнопка подключения для них недоступна. Конфигурацию можно построить для VLESS с TLS или Reality (TCP либо gRPC) и Hysteria2 без нестандартных параметров Xray. Ссылки с `fm`, `pcs`, шифрованным VLESS и Hysteria2 с закреплённым сертификатом требуют интеграции Xray-ядра. Число серверов и совместимых конфигураций зависит от текущего содержимого подписки; доступность каждого сервера проверяется при подключении. Переход на Xray потребует замены ядра и Android TUN-моста: два независимо собранных Go-ядра нельзя безопасно загружать в один процесс.

## Сборка

Нужны JDK 17, Android SDK Platform 35, Build Tools 35, Android NDK 27.2.12479018, Go 1.25 или новее и `github.com/sagernet/gomobile/cmd/gomobile@v0.1.12` в `PATH`. `libbox.aar` не хранится в Git. Сначала соберите его через [build-libbox.ps1](build-libbox.ps1), затем запустите `gradlew.bat assembleDebug` из этой папки. Скрипт собирает исходники официального тега sing-box v1.14.4 для `arm64-v8a` и `armeabi-v7a` и кладёт AAR в `app/libs`.

Отладочный APK: `app/build/outputs/apk/debug/app-debug.apk`. Установка: `adb install -r app/build/outputs/apk/debug/app-debug.apk`. Синтетические ссылки в `tests/test-subscription.txt` проверяют импорт и не подходят для реального подключения.

Подписка загружается по HTTPS. Адрес подписки, ID устройства и выбранные настройки хранятся в закрытом хранилище приложения; резервное копирование отключено. Серверные ссылки не выводятся в журнал. Перед публичным выпуском потребуются персональные подписки и проверка лицензий зависимостей.
