# Pipidastr VPN для Android и Android TV

Клиент импортирует HTTPS-подписку, показывает все серверы и подключается через Android `VpnService` и официальный `libXray` v26.11.9. На телефоне подключение остаётся неподвижным, прокручивается только список серверов; поиск находится над списком, настройки открываются кнопкой с тремя полосками. На телевизоре список серверов занимает левую колонку, а подключение и компактные настройки находятся справа.

При первом подключении Android запрашивает разрешение на создание VPN. Если список приложений пуст, через VPN направляется весь трафик. Иначе `VpnService` включает только выбранные пакеты. После запуска клиент проверяет доступ к сайту через VPN и сообщает об ошибке, если сервер не передаёт трафик. Подписка восстанавливается после перезапуска приложения. На телефоне поиск фильтрует серверы по имени, адресу и протоколу.

После подключения VPN работает как фоновая служба Android с постоянным уведомлением. На Android TV значок приложения открывает окно клиента. В установленном Plume короткое нажатие кнопки VPN переключает выбранный сервер, а удержание открывает окно Pipidastr. Патч лаунчера находится в `tools/Plume-v1.7.1-pipidastr.patch`. При первом подключении откроется системный запрос разрешения. Удержание значка на главном экране обрабатывает лаунчер телевизора, а не приложение.

Телефон может прочитать QR-код подписки камерой или из изображения. Для передачи подписки на телевизор откройте на нём «Добавить подписку» → «Получить с телефона по QR», затем считайте QR-код телефоном с запущенным Pipidastr VPN. Оба устройства должны быть в одной сети Wi-Fi. Код действует две минуты; ссылка передаётся в зашифрованном виде. На ТВ также доступны ручной ввод ссылки и обновление серверов.

Ядро Xray преобразует ссылки VLESS и Hysteria2 в конфигурацию, в том числе ссылки с `fm`, `pcs` и шифрованным VLESS. Подключение каждого сервера проверяется отдельно: совместимость формата ссылки не гарантирует, что удалённый сервер сейчас доступен. На проверенной подписке телефон и телевизор распознали 205 из 205 серверов; действующее число зависит от подписки.

## Сборка

Версия 0.6 добавляет кнопки «Тест пинга», «Обновить подписку» и «Найти резервный сервер» рядом со списком на телефоне и телевизоре. Пинг измеряет время TCP-подключения через физическую сеть; для Hysteria2 показывается отметка UDP. Это проверка доступности порта, а не гарантия работы VPN.

Если прямой маршрут не передаёт HTTPS, клиент перебирает доступные VLESS-резервы и проверяет полную цепочку до выбранного сервера. Успешный резерв сохраняется и проверяется первым при следующем поиске. Кнопка поиска запускает переподключение; его можно отменить кнопкой «Отменить». При обновлении подписки действующее подключение сохраняется. На Android 13 и новее локальная подсеть исключена из VPN для доступа к приставке и передачи подписки по QR. Этапы и ошибки подключения доступны в `adb logcat -s PipidastrVPN`.

Нужны JDK 17, Android SDK Platform 35 и Build Tools 35. `libXray.aar` не хранится в Git. Запустите [build-libxray.ps1](build-libxray.ps1): скрипт загружает официальный архив [libXray v26.11.9](https://github.com/XTLS/libXray/releases/tag/v26.11.9), проверяет SHA-256 и кладёт AAR в `app/libs`. Затем запустите `gradlew.bat assembleDebug` из этой папки. AAR содержит библиотеки для `arm64-v8a` и `armeabi-v7a`.

Отладочный APK: `app/build/outputs/apk/debug/app-debug.apk`. Установка: `adb install -r app/build/outputs/apk/debug/app-debug.apk`. Синтетические ссылки в `tests/test-subscription.txt` проверяют импорт и не подходят для реального подключения.

Подписка загружается по HTTPS. Адрес подписки, ID устройства и выбранные настройки хранятся в закрытом хранилище приложения; резервное копирование отключено. Серверные ссылки не выводятся в журнал. Перед публичным выпуском потребуются персональные подписки и проверка лицензий зависимостей.
